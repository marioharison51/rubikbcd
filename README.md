# Rubik BCD

Application Rubik Cube avec inscription locale et interface mobile.

## Build Android APK

1. Ouvrir Android Studio.
2. Ouvrir le dossier [android_app](android_app).
3. Laisser Android Studio synchroniser Gradle.
4. Dans Build > Generate Signed Bundle / APK, choisir APK.
5. Générer le fichier APK signé.

## Fonctionnement

- Première utilisation : créer un compte local.
- L’application garde les informations sur l’appareil.
- Elle peut être installée comme une application native sur Android.
